HEALTHCARE / LIFE SCIENCES · MULTI-AGENT ON AWS · ROLE: ARCHITECTURE & DELIVERY

Clinical trial AI automation

The problem. Clinical sourcing ran on people reading contracts. Protocol analysis, MSA review and vendor evaluation each meant opening long documents and comparing them by hand, so the procurement cycle moved at the speed of whoever happened to be reading.

The design call. Separate competencies, separate agents. Reading an MSA, diffing two documents and drafting a statement of work need different tools, so I standardised tool use across them with the Model Context Protocol rather than hard-wiring each integration, and scoped every agent with its own IAM role.

  • Agent layer: Orchestrator, MSA intelligence, document comparison, SOW generation, on Amazon Bedrock
  • Retrieval: Amazon OpenSearch vector index across protocols, MSAs & vendor docs
  • Execution: serverless microservices on AWS Lambda behind API Gateway, sized for highly variable workloads
  • Security: every agent and service scoped by its own strict IAM role
⚡ Accelerated procurement lifecycles · manual sourcing analysis → agent-driven & traceable
